# CMME — Recueil dentaire

Application de bureau macOS, locale et hors ligne, pour le recueil clinique dentaire des consultations TCA de la CMME
(Sainte-Anne) et l'exploitation statistique, rétrospective en priorité. Aucun cloud, aucune IA, aucune télémétrie.

- Fichier maître : `PROJET-MAITRE.md` · Spécifications d'origine : `specs/`
- Guide : `docs/GUIDE_UTILISATEUR.md` · Installation et build : `docs/INSTALLATION.md`
- Recette exécutée : `docs/RECETTE_RESULTATS.md` · Limites : `docs/LIMITES.md`

Tests : `cargo test -p cmme-core`. Build : `npx tauri build`.
Données fictives uniquement dans ce dépôt.
