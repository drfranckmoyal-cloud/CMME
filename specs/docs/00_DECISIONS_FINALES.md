## Interprétations de mise en œuvre

- HBD reste indépendant du protocole et peut coexister avec modéré/avancé/personnalisé. Décocher la case ne doit pas automatiquement signifier « enseignement non réalisé » : état non renseigné tant qu'aucune réponse négative n'est explicite.
- « Aucun protocole proposé » est une réponse affirmative à une question de recueil, distincte de « Non renseigné ». Il ne signifie pas « aucune prévention » si HBD est consigné.
- Pour l'alimentation, « aucun rapporté » est exclusif des catégories positives ; un menu laissé vide signifie non renseigné.
- Les valeurs entre parenthèses restent précises si elles sont réellement numériques ; une plage dans les parenthèses reste une plage, pas un nombre exact.
- Les boutons de protocole préparent des mesures à confirmer. Ils ne prouvent pas qu'un produit a été délivré ou utilisé.

## Choix proposés, sans nouvelle question bloquante

- Bureau local mono-utilisateur, cible de travail macOS, architecture native sécurisée. Vérification technique du Mac avant distribution.
- Iris en thème initial de développement ; Lagune disponible. Aucun thème n'est définitivement choisi par Franck.
- Police de travail DM Sans, titres Manrope ; assets embarqués dans l'application livrée.
- Les fenêtres de référence proposées dans le dictionnaire (28 jours pour vomissements, 7 jours pour certaines habitudes) sont à confirmer cliniquement ; affichées explicitement, jamais imposées à l'historique.
